# Linux Security Analysis

This repository contains hands-on Linux security analysis exercises focused on **text processing, filtering, permissions, and defensive reasoning** using standard CLI tools.

The goal is to demonstrate how raw system data can be transformed into reliable security insights by avoiding assumptions and validating results step by step.

---

## 🔍 Topics Covered

- Text filtering and normalization
- User and permission analysis
- Regex usage in configuration files
- Defensive command-line workflows
- Accurate counting and validation

---

## 📂 Contents

### 🔹 Passwd File Analysis
Practical analysis of `/etc/passwd` to extract users, UIDs, shells, and identify valid login accounts.

### 🔹 Regex and Filtering Practice
Hands-on use of grep, extended regex, and filtering logic applied to real configuration files such as `sshd_config`.

---

## 🧠 Methodology

Each write-up focuses on:
- the **problem**
- the **common assumption trap**
- the **validation approach**
- the **security-relevant conclusion**

This mirrors real-world Blue Team and SOC workflows.
